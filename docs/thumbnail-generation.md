# Thumbnail Generation

## Model

**FLUX.1-schnell** via Together AI API (free tier, 10 img/min rate limit).

- Resolution: 512x512
- Configurable via `IMAGE_MODEL` env var

## Prompt Generation

Prompts are generated by **Claude Haiku** via the Anthropic API. The LLM receives track metadata (title, styleTags, BPM, key) and produces a single image generation prompt.

### System prompt rules

- Vivid surreal scenes, abstract 3D objects, macro textures, or dreamlike landscapes
- Title inspires the *concept* but its literal words are never included
- Each track variant (edits, remixes) gets a distinctly different visual concept
- Genre, BPM, and key inform texture, energy, and color palette
- Bold simple compositions — must read well at 128x128
- Never mention text/typography/letters/words — FLUX renders text well, so even "no text" triggers it
- No people, faces, signage, labels, logos, or UI elements

### Why LLM over templates

Rule-based prompt builders produced repetitive results across track variants and couldn't handle title-inspired concepts without leaking literal words into the prompt (which FLUX renders as visible text). Claude understands semantic meaning and produces unique visual concepts per track.

## Output

All files are written to the track directory (`../paincave-tracks/{hash}/`):

| File | Size | Purpose |
|------|------|---------|
| `thumbnail.png` | 512x512 | Source image from FLUX |
| `thumbnail-256.png` | 256x256 | High-res app thumbnail |
| `thumbnail-128.png` | 128x128 | Standard app thumbnail |
| `thumbnail-64.png` | 64x64 | Small/list view thumbnail |

Resizing uses Pillow with LANCZOS filter.

## Known Constraints

- **FLUX text generation**: Any mention of text in the prompt — even negative ("no text") — causes visible text in the output. The fix is to never reference text at all.
- **Together AI free tier**: FLUX.1-schnell is free but rate-limited to 10 images/minute.
