# Thumbnail Generation

## Model

**FLUX.1-schnell** via Together AI API (free tier, 10 img/min rate limit).

- Resolution: 512x512
- Configurable via `IMAGE_MODEL` env var

## Prompt Generation

Prompts are generated by **Claude Haiku** via the Anthropic API. The LLM receives track metadata (title, styleTags, BPM, key) and produces a single image generation prompt.

### System prompt rules

- Surrealist fine art style — Magritte, de Chirico, Dalí
- Night cities, glowing windows, neon reflections, rain-slicked streets
- Dramatic cloud formations, skies that dominate the frame
- Surreal cityscapes, impossible architecture, liminal spaces
- Cosmic vistas, nebulae, planets, vast empty space
- Silhouetted figures, distant people, mysterious observers
- Dreamlike atmosphere, mysterious and contemplative
- Rich color palettes, dramatic lighting, deep shadows
- Title inspires the *concept* loosely, but literal words never included
- BPM informs mood: slow = mysterious/meditative, fast = intense/dynamic
- Bold simple compositions — must read well at 128x128
- Never mention text/typography — FLUX renders text well, so even "no text" triggers it

### Why LLM over templates

Rule-based prompt builders produced repetitive results and couldn't handle title-inspired concepts without leaking literal words into the prompt (which FLUX renders as visible text). Claude understands semantic meaning and produces unique visual concepts per track.

## Output

All files are written to the track directory:

| File | Size | Purpose |
|------|------|---------|
| `thumb.webp` | 512x512 | Full resolution source |
| `thumb_256.webp` | 256x256 | High-res app thumbnail |
| `thumb_128.webp` | 128x128 | Standard app thumbnail |
| `thumb_64.webp` | 64x64 | Small/list view thumbnail |

Resizing uses Pillow with LANCZOS filter. WebP quality is 85.

## Known Constraints

- **FLUX text generation**: Any mention of text in the prompt — even negative ("no text") — causes visible text in the output. The fix is to never reference text at all.
- **Together AI free tier**: FLUX.1-schnell is free but rate-limited to 10 images/minute.
